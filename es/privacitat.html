Los servidores

La web la sirve GitHub y los datos del tiempo se descargan de IONOS. Como cualquier web, pueden registrar la dirección IP de las visitas; esta web no hace ningún uso de ella.

Avisos en el móvil o en el ordenador

Se guarda, en IONOS, la dirección anónima que da el navegador para enviarte notificaciones, los avisos y las horas que eliges y el idioma. «Desactivar» lo borra; si el navegador anula la dirección, también se borra. Se cuentan las altas y las bajas de cada día, sin saber quién. Las notificaciones pasan por el servicio de tu navegador (Google, Apple, Mozilla o Microsoft).

Bot de Telegram

Se guarda tu identificador de Telegram, lo que eliges, el idioma y el día del alta; /baixa lo borra todo. También se cuentan las altas y las bajas y cuántas veces se usa cada orden cada día, sin saber quién.
